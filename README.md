# Finance & Governance Lab Resources

Official public resource repository for Finance & Governance Lab (FGL).

FGL website: https://www.financegovernancelab.com/

## Purpose

This repository is intended to hold public downloadable FGL assets such as:

- professional tools and calculators;
- templates and checklists;
- selected case-brief downloads;
- datasets and supporting documentation;
- versioned release notes.

The FGL website remains the primary publishing and discovery layer. This repository is the controlled asset and version repository.

## Repository structure

- `tools/` — calculators, utilities and professional tools
- `templates/` — reusable finance, audit and controls templates
- `checklists/` — practical professional checklists
- `case-briefs/` — selected downloadable FGL reference briefs
- `datasets/` — public datasets supporting FGL tools or analysis
- `documentation/` — user guides, methodology notes and release documentation
- `archive/` — superseded public assets retained for history where appropriate

## Versioning approach

Major downloadable tools should be distributed through GitHub Releases rather than by repeatedly overwriting a file.

Example:

- `v1.0` — first public release
- `v1.1` — minor corrections or improvements
- `v2.0` — material redesign or functionality change

Each release should identify:

- asset name;
- version;
- release date;
- relevant financial year or regulatory period where applicable;
- source/methodology notes;
- important changes;
- known limitations;
- related FGL article or tool page.

## Publishing control

A file appearing in this repository does not replace the corresponding FGL article, guide or tool page.

Where available, each public resource should point readers back to its permanent FGL page.
